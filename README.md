# YouTube Comments

운명원 유튜브 댓글 에이전트 대시보드 — 내 컴퓨터에서 도는 작은 웹 프로그램입니다. 영상을 찾아 고르면 AI가 댓글 초안을 써 주고, **사람이 버튼을 눌러** 크롬에서 한 글자씩 직접 입력해 댓글을 답니다.

---

## 실행 방법 — 더블클릭 하나 (설치 필요 없음)

파이썬 같은 걸 따로 깔지 않아도 됩니다. (댓글을 실제로 올리려면 **구글 크롬**만 있으면 됩니다.)

1. **`YouTubeComments.exe`** 를 더블클릭합니다. (이 저장소 파일, 또는 [**Releases**](../../releases) 에서 받은 파일)
2. 작은 **제어 창**이 뜨고 브라우저에 `http://127.0.0.1:8765/` 가 열립니다.
   - 제어 창 버튼: **[브라우저 열기] · [다시 켜기] · [끄기/켜기] · [데이터 폴더 열기]**
   - 제어 창을 닫으면 프로그램이 꺼집니다. (bat·command 같은 스크립트는 필요 없습니다 — exe 하나로 켜고/끄고/다시 켭니다.)
3. 처음 열면 **시작 전 준비** 화면이 나옵니다.
   - **① AI 연결** — 두 가지 중 하나로 연결하고 [연결 시험]이 '연결됨'이면 됩니다. (방법은 화면 카드 안에 단계별로 안내됩니다)
     - **API 키** — Claude · GPT · Gemini 중 하나의 키를 넣습니다(사용한 만큼 결제).
     - **이 PC의 AI 프로그램** — 키 없이, 이미 로그인해 쓰는 Claude Code나 다른 에이전트(Codex · Hermes 등)를 연결합니다.
   - **② 유튜브 계정 로그인** — [로그인]으로 열린 크롬 창에서 구글에 로그인하고, 창을 닫은 뒤 [상태 확인]을 누릅니다.
4. 준비가 끝나면 **[시작하기 →]** 로 운영 화면으로 갑니다.
   - ① 영상 찾기(키워드·링크, 여러 개 선택) → 뒤에서 초안 3개 작성 → ② 글 확인(고르고 다듬기) → ③ 올리기(사람이 클릭).

> 처음 실행할 때 Windows가 "PC 보호" 경고를 띄우면, 서명이 없는 프로그램이라 그렇습니다. **[추가 정보] → [실행]** 을 누르면 됩니다.

데이터(설정·키·기록·로그인)는 실행 파일 바깥 `%LOCALAPPDATA%\YouTubeComments` 에 저장되어, 새 버전으로 바꿔도 그대로 남습니다.

---

## 운영 규칙

- 영상당 댓글 1개, 하루 상한 기본 10개(전 계정 합산·자정 초기화).
- 댓글은 40~120자, 영상 속 장면·말을 1개 이상 인용, 링크·해시태그·지어낸 후기 금지, '운명원' 1회.
- 게시는 **항상 사람이** [올리기]를 눌러야 합니다. 초안 작성만 여러 개 동시에 돕니다.
- 유튜브 채널이 없는 구글 계정으로는 댓글을 달 수 없습니다(자동으로 걸러집니다).
- 이 PC 주소(`127.0.0.1`)로만 열리고, 다른 사이트가 보낸 요청은 받지 않습니다.
- API 키는 이 PC의 `.env` 파일에만 저장되고, 화면에는 끝 4자리만 보입니다.

## 필요한 것

- Windows 10/11 (64비트)
- 댓글 게시에는 구글 크롬
- 초안 작성에는 Claude / GPT / Gemini 중 하나의 API 키, 또는 이 PC에 로그인된 AI 프로그램(Claude Code · Codex · Hermes 등)
