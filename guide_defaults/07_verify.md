# ⑦ 내 댓글 · 로그아웃 화면 확인

## 하는 일
1. 게시 직후 새로고침 → '최신순' 정렬 → **내 채널 핸들**과 문장이 모두 맞는 댓글을 찾아요.
2. `logged_out_check`가 켜져 있으면, 로그인하지 않은 새 크롬으로 같은 댓글이 보이는지 한 번 더 확인해요(스팸 필터로 숨겨졌는지).

## 결과
- 보여요 ✓ · 안 보여요(스팸 필터 추정) · 확인 못 함 — 기록에 남고 캡처를 볼 수 있어요.
- 못 찾으면 '확인 필요'로 잠그고, 영상에서 직접 확인하도록 안내해요.
